# `Html/adjust_history.html` — ประวัติการปรับ / ยืนยัน

จัดทำ 2026-08-13

## หน้านี้ทำอะไร

แสดง **"การตัดสิน" ทั้งหมดของรอบหนึ่ง** พร้อมค้นหา / กรอง / เรียง / Export / คืนค่า

เป็นหน้าเต็มของ modal เดิมในหน้า Match ยอด (ปุ่ม "ประวัติ / คืนค่า") ซึ่งยังใช้งานได้เหมือนเดิม
— modal เหมาะกับดูเร็ว ๆ ระหว่างทำงาน · หน้านี้เหมาะกับค้นหาและทำรายงาน

⚠️ **"การตัดสิน" ไม่ใช่ "ผลนับ"** — หน้านี้ไม่แตะ `inventory_counts` เลย
ประวัติการแก้/ลบผลนับอยู่คนละที่ (ปุ่ม "ประวัติการแก้ไข/ลบ" ในหน้า ตรวจสอบ ซึ่งอ่าน `inventory_audit_logs`)

## แหล่งข้อมูล

| ตาราง | ความหมาย | แสดงเป็น |
|---|---|---|
| `stock_adjustments` | ยอดปรับ — "ผลนับคือยอดจริง" | ยอดปรับ (ร่าง / ปรับแล้ว) |
| `reconciliation_match_acceptances` | ยืนยันเป็นถูกต้อง — "ยอด Excel คือยอดจริง" | ยืนยันถูกต้อง |

รวมสองแหล่งด้วย `RS.buildAdjustHistoryEntries()` ใน `Js/reconcile-shared.js`
(**ตัวเดียวกับที่ modal ในหน้า reconcile ใช้** — กติกาอยู่ที่เดียว ห้ามคัดลอก)

## ตัวกรอง

| ช่อง | พฤติกรรม |
|---|---|
| ประเภท | ทั้งหมด / ยอดปรับ / ยอดปรับ–ปรับแล้ว / ยอดปรับ–ร่าง / ยืนยันถูกต้อง |
| SKU | contains, ไม่สนตัวพิมพ์ (normalize UPPERCASE ตาม invariant ข้อ 2) |
| รายละเอียด | contains, ไม่สนตัวพิมพ์ |
| วันที่ตั้งแต่ / ถึงวันที่ | **เวลาไทย** · "ถึงวันที่" รวมทั้งวันนั้น · แถวที่ไม่มีเวลาจะถูกตัดออกเมื่อระบุช่วง |
| จำนวนที่ปรับ | ต่ำสุด–สูงสุด ใช้ **ค่าจริงมีเครื่องหมาย** · แถว "ยืนยันถูกต้อง" ไม่มีจำนวน จึงหลุดออกเมื่อระบุช่วง |

ทุกช่องว่าง = ไม่กรอง · เกณฑ์รวมกันแบบ AND · กรองฝั่งเบราว์เซอร์ทั้งหมด (โหลดทั้งรอบมาแล้ว)

## การเรียง

คลิกหัวคอลัมน์เพื่อสลับ ▲/▼ — ประเภท · SKU · จำนวน · วันเวลา (ค่าเริ่มต้น: ใหม่→เก่า)

- **จำนวนเรียงตามค่าจริงมีเครื่องหมาย** (+225 > +1 > −101) ไม่ใช่ขนาด
  — ให้ตรงกับคอลัมน์ "ต่าง" ในหน้า Match ที่คืนทิศทาง (M3)
- แถวที่ไม่มีจำนวนไปท้ายเสมอ ทั้งเรียงขึ้นและลง
- ค่าเสมอกัน tiebreak ด้วย SKU แล้ววันเวลา ⇒ ลำดับไม่สลับเองระหว่าง render

## Export

**Excel (.xlsx)** และ **CSV** — ส่งออก **ตามที่กรองและเรียงอยู่บนจอ** ไม่ใช่ข้อมูลดิบทั้งรอบ

คอลัมน์: `ประเภท · SKU · จำนวน · สถานะ · รายละเอียด · โดย · วันเวลา (ไทย)`

ชื่อไฟล์: `ประวัติการปรับ-ยืนยัน_<คลัง>_<รอบ>_<YYYY-MM-DD_HHmm>.xlsx`

- ชื่อฟีเจอร์ใช้ `-` แทน `/` เพราะ `/` ใช้ในชื่อไฟล์ไม่ได้ · อักขระต้องห้ามอื่น (`\ : * ? " < > |`) ถูกแทนด้วย `-` ด้วย
  (สำคัญกับรอบหลายคลัง ซึ่ง warehouse เก็บเป็น `"A|B"`)
- เวลาเป็น Asia/Bangkok จริง ไม่ใช่ timezone ของเครื่อง
- CSV มี BOM นำหน้า — ไม่มีแล้ว Excel เปิดภาษาไทยเป็นขยะ

## ปุ่มคืนค่า

เหมือน modal เดิมทุกขั้น: เลือก → ยืนยัน 2 ขั้น → `clearAdjustmentsAndMatchAcceptancesForSkus`
(เขียน `inventory_audit_logs` ก่อนลบเสมอ) → `refresh_reconciliation_for_cycle` → โหลดรายการใหม่

⚠️ **คืนค่าเป็นราย SKU ทั้งการตัดสินในรอบนั้น** ไม่ใช่ต่อแถวที่ติ๊ก
ติ๊กแถว "ยอดปรับ" ของ SKU X ⇒ การยืนยันของ X ในรอบนั้นก็หายด้วย · **ผลนับไม่ถูกแตะ**

กติกาความปลอดภัยที่เพิ่มจาก modal เดิม (เพราะหน้านี้มีตัวกรอง):

- "เลือกทั้งหมด" เลือกเฉพาะแถวที่**มองเห็นหลังกรอง**
- เปลี่ยนตัวกรอง / เปลี่ยนการเรียง / เปลี่ยนรอบ ⇒ ล้างสิ่งที่เลือกทิ้ง
- ล็อก cycle id ก่อนเปิด modal ยืนยัน แล้วตรวจซ้ำหลัง modal ปิด (บทเรียน H5)
